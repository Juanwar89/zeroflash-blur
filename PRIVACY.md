# Privacy Policy — ZeroFlash Blur

Last updated: November 2026

ZeroFlash Blur is a local browser privacy utility that visually blurs sensitive elements on webpages during screen sharing and recordings.

## Data Collection
ZeroFlash Blur does **not** collect, transmit, sell, or share any personal, financial, browsing, or webpage content data.

## Local Processing & Storage
- All pattern detection (emails, currencies, cards, phone numbers, API keys) runs 100% locally inside your browser.
- User settings (blur intensity, language, detector toggles, and saved CSS selectors per site) are stored locally using `chrome.storage.local` and never leave your device.
- No analytics, tracking scripts, ads, or external API calls are performed by the extension.
